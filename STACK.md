# SmartQuiz — Tech Stack

## Frontend
- React 18 + Vite
- React Router DOM v6
- Context API (Auth + Quiz state)
- Axios
- Recharts (analytics)
- Plain CSS with CSS variables (light theme) — no heavy UI framework, for full design control

## Backend
- Node.js + Express
- MongoDB + Mongoose
- JWT (jsonwebtoken) + bcryptjs
- dotenv, cors

## Tooling
- ESLint
- Nodemon (dev)
